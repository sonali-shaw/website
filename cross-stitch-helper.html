Cross-Stitch Helper
A browser-based tool that turns any dropped photo into a real, stitchable cross-stitch chart — not a blurred-out pixelation of the original, but a pattern built from a genuinely limited, k-means-derived thread palette. Drop an image in and it's immediately gridded, quantized, and ready to work from: zoom into printable sections, click any square to isolate its color across the whole piece, hand-edit individual stitches, and export a numbered, section-lined chart as a PDF.

Technical Deep Dive
How Cross-Stitch Helper Works
Not Just Pixelation — K-Means Color Quantization

Naive "pixelation" just averages the pixels in each grid cell and paints that exact average back — which sounds like enough, but isn't: a photo has effectively unlimited gradation, so every cell can land on a subtly different shade from its neighbor. That's fine for a mosaic effect, but it's useless for actual cross-stitch, where you're buying a finite spool of floss colors and every square has to match one of them.

Instead, once each cell's average color is computed, the tool runs k-means clustering (with k-means++ weighted seeding, so starting centroids spread out instead of clumping) over every cell's color to find a small set of representative clusters, then snaps each cell to its nearest cluster center. The output is a real, bounded palette — the actual constraint of the craft — rather than an image that merely looks blockier. The color-count slider itself is capped dynamically too: cell colors are converted to Lab space and greedily grouped by CIE76 ΔE, so the maximum you can even ask for is however many colors a person could actually tell apart in that specific photo, not an arbitrary number.

Dithering & Perceptual Color Matching

An optional Floyd–Steinberg error-diffusion pass runs per grid cell rather than per pixel: each cell is matched to its nearest palette color, and the resulting quantization error is spread to not-yet-visited neighboring cells, softening hard transitions instead of every cell rounding independently. A serpentine mode alternates scan direction each row to avoid directional streaking. Separately, a "perceptual" color- mapping option swaps the default Euclidean RGB distance for a redmean-weighted distance — both for k-means clustering and for matching each cell to its nearest color — which tracks human color perception more closely than flat RGB distance.

Section View, Manual Editing & Isolate

Large patterns are unreadable as one flat grid, so Section View splits the pattern into clickable, printable chunks (size adjustable) that zoom to fill the canvas — the same chunking a printed cross-stitch chart uses across multiple pages. Manual Edit, available only once zoomed into a section, lets you select any single stitch and reassign it to an existing palette color or a brand-new one picked from a color wheel. A small eye-slash icon next to each palette color isolates just that color across the whole pattern (all other squares go blank) so you can trace exactly where one thread color is used.

Export & Practical Details

"Export PDF" renders a dedicated, full-resolution version of the chart — every cell's color, a black grid, bold black lines at each section boundary, and each cell's palette number for stitching by hand — and hands it to the browser's native print dialog, where "Save as PDF" produces the file directly, with no external PDF library involved. A live Pattern Data panel estimates floss skeins needed and a rough complexity rating, and charts how many stitches use each color. Slider drags are debounced rather than regenerating the whole pattern on every tick, since a full regeneration re-reads pixel data, reruns k-means, and repaints every cell.
